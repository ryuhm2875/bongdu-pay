FIREBASE 연동 설정
아래 3단계를 따라하면 PC간 실시간 동기화가 돼요!
1
Firebase 프로젝트 만들기
console.firebase.google.com 접속 → 구글 계정으로 로그인 → 프로젝트 추가 클릭 → 이름 입력 (예: 봉두페이) → Google Analytics 사용 안함 → 프로젝트 만들기
2
Realtime Database 만들기
왼쪽 메뉴 빌드 → Realtime Database 클릭 → 데이터베이스 만들기 → 위치: 미국(기본값) → 다음 → 테스트 모드에서 시작 선택 → 사용 설정
그 다음 규칙 탭 클릭 → 아래 코드로 교체 후 게시: {"rules":{".read":true,".write":true}}
3
데이터베이스 URL 복사
Realtime Database 화면 상단에 있는
https://봉두페이-xxxxx-default-rtdb.firebaseio.com/
이 주소를 복사해서 아래에 붙여넣기 하세요.
💡 URL을 한 번 입력하면 저장되므로 다음부터는 바로 열려요.
여러 PC에서 같은 URL과 교실 이름을 입력하면 데이터가 자동으로 공유됩니다.
